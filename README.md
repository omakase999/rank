# AD RANK 자동화 프로그램 v3.0 - 설정 가이드

## 프로그램이 하는 일

```
구글 시트에서 상호명+키워드 읽기
→ adrank.co.kr(리뉴얼 사이트) 자동 로그인
→ 플레이스 분석 API 호출로 순위/점수/주소/MID 추출 (최대 300위)
→ 구글 시트에 오늘 날짜 열에 기록
```

## v3.0 변경사항 (2026-09-22, 사이트 리뉴얼 대응)

- 2026-08-10 애드랭크 리뉴얼로 구버전(v2.0)이 동작 불가 → 전면 수정
- 페이지 주소 변경: `/placeMng/placeAnalyze` → `/place/analyze`
- 자동 로그인 성공 시 **Enter 없이 바로 검색 시작** (GUI/콘솔 공통)
- 로그인 직후 온보딩 팝업 자동 닫기
- 검색은 화면 클릭 대신 **분석 API 직접 호출** (더 빠르고 안정적, 최대 300위까지)
- MID/네이버 URL은 API 응답에서 바로 추출 (상호 클릭 불필요)
- 동일 상호 구분: "키워드 목록"이 사라져서 **주소**로 대조
  → 키워드 시트 F열에 매장 주소(예: `수원 영통구 이의동`) 입력
- 점수: 네이버 지표 제공 중단(2026-09-18 공지)으로 사이트 화면상 종합점수는 0.
  프로그램은 API의 기준일 점수(rankScoreOld)를 기록

## STEP 1. Python 설치 (처음 1번만)

1. https://www.python.org/downloads/ 접속
2. 노란색 **Download Python** 버튼 클릭
3. 설치 시작 화면에서 **"Add Python to PATH"** 반드시 체크 ☑
4. **Install Now** 클릭

---

## STEP 2. 구글 시트 API 설정 (처음 1번만)

### 2-1. Google Cloud 프로젝트 만들기

1. https://console.cloud.google.com/ 접속 (구글 로그인)
2. 상단 프로젝트 선택 → **새 프로젝트** → 이름: `adrank-auto` → **만들기**

### 2-2. API 활성화

1. 왼쪽 메뉴 → **API 및 서비스** → **라이브러리**
2. 검색창에 `Google Sheets API` 입력 → 클릭 → **사용** 버튼
3. 다시 라이브러리로 돌아가서 `Google Drive API` 검색 → **사용** 버튼

### 2-3. 서비스 계정 만들기

1. 왼쪽 메뉴 → **API 및 서비스** → **사용자 인증 정보**
2. **+ 사용자 인증 정보 만들기** → **서비스 계정**
3. 서비스 계정 이름: `adrank-bot` → **완료**
4. 만들어진 서비스 계정 이메일 클릭
5. **키** 탭 → **키 추가** → **새 키 만들기** → **JSON** → **만들기**
6. JSON 파일이 자동 다운로드됩니다

### 2-4. 다운로드된 파일 처리

- 파일 이름을 `credentials.json`으로 변경
- `adrank_auto` 폴더에 넣기

---

## STEP 3. 구글 시트 준비

### 3-1. 시트 공유 설정

1. 사용할 구글 시트 열기
2. 오른쪽 상단 **공유** 버튼
3. `credentials.json` 파일을 메모장으로 열고 `client_email` 값 복사
4. 이 이메일을 **편집자** 권한으로 공유

### 3-2. 시트 구조 (4행 단위)

시트 이름: **트래픽테스트** (config.json에서 변경 가능)

```
     A      B           C          D     E      F         G      H     ...
1  전체:N  (빈칸)      성승:0    하락+유지:0         5/30   5/31   ...
2         상호        키워드     순위    점수    비고      토      일    ...
3  일반   피다테르    수원부케                  진행일:N   ← 순위   ...
4                                              5일비교    ← 점수   ...
5         1027978575                           작업량
6         https://m.place...                   반영일:0
7  맛집   김개똥피부과  청담동피부과            진행일:N   ← 순위   ...
8                                              5일비교    ← 점수   ...
9         (MID자동입력)                        작업량
10        (URL자동입력)                        반영일:0
...
```

**이미 입력해야 하는 것:**
- A열: 타입 (일반/맛집)
- B열 (3,7,11행...): 상호명
- C열 (3,7,11행...): 키워드

**프로그램이 자동으로 채우는 것:**
- B열 (5,9,13행...): 네이버 MID 숫자
- B열 (6,10,14행...): 네이버 URL 전체
- D열: 최신 순위
- E열: 최신 점수
- G열~ (날짜별): 순위와 점수

## STEP 4. config.json 설정

```json
{
    "google_credentials_file": "credentials.json",
    "google_sheet_url": "https://docs.google.com/spreadsheets/d/실제URL/edit",
    "sheet_name": "트래픽테스트",
    "data_start_row": 3,
    "row_interval": 4,
    "date_start_column": 7,
    "search_wait_seconds": 5,
    "between_search_delay": 3
}
```

| 항목 | 설명 |
|:-----|:-----|
| sheet_name | 구글 시트 탭 이름 |
| data_start_row | 첫 번째 업체가 시작하는 행 (기본: 3행) |
| row_interval | 업체당 행 간격 (기본: 4행) |
| date_start_column | 날짜가 시작하는 열 (G=7) |
| search_wait_seconds | 검색 후 대기 시간 (느리면 7~10으로) |

## STEP 5. 설치 및 실행

### 최초 설치
`setup.bat` 더블클릭

### 매일 실행
1. `run.bat` (또는 `gui.bat`) 더블클릭
2. 자동 로그인 성공 시 **바로 자동 실행** (Enter 불필요)
3. 자동 로그인 실패 시에만: 브라우저에서 직접 로그인 후 Enter

---

## 문제 해결

| 증상 | 해결 |
|:-----|:-----|
| 결과 추출 안됨 | search_wait_seconds를 7~10으로 늘리기 |
| 상호명 매칭 안됨 | 시트의 상호명이 adrank 결과와 정확히 같은지 확인 |
| MID 추출 안됨 | 상호 클릭 시 네이버 페이지가 열리는지 수동 확인 |
| 구글 시트 오류 | credentials.json 위치 + 시트 공유 설정 확인 |
| 날짜 열 안 찾음 | 1행의 날짜 형식이 "5/30" 같은 형태인지 확인 |
